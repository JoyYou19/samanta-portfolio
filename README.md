Defining the design


1. Square corners = the work itself, if we are showing work, we have square corners

2. Rounded corners = objects you can interact with, if it behaves like an object you can manipulate, it can be soft

3. Liquid glass = the interface between Samanta and the work, glass means the information sits on top and the project underneath

4. Handwritten font = Samantas voice, this means that everything that is hand written should think like Samanta is speaking it or signing it

5. The portfolio UI is soft, the work is precise, that is what I want to convey here
